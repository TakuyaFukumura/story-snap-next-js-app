# ガウシアンぼかし対応の検討結果

## 結論

ブラウザの Canvas 2D API が提供する `context.filter = "blur(...)"` を利用することで、追加ライブラリなしにガウシアンぼかしを実装できます。画像と顔検出はこれまでどおりブラウザ内で完結し、サーバーへの画像アップロードも発生しません。

今回、既存のブロックモザイクを残したまま加工方法を選択できるようにし、初期値を「ガウシアンぼかし」に変更しました。強度は既存の「弱・中・強」を共通利用し、ぼかし半径はそれぞれ 6px、12px、18px としています。

## 実装方針

- 選択範囲の画像データを一時 Canvas にコピーする。
- 一時 Canvas を `filter: blur(...)` で描画し、選択範囲にクリップして元 Canvas へ戻す。
- 既存のブロックモザイクは「ブロックモザイク」として選択可能にする。
- 顔領域と手動追加領域のどちらにも同じ加工方法・強度を適用する。
- 保存時は既存の JPEG / PNG 出力処理をそのまま利用する。

## 注意点

`CanvasRenderingContext2D.filter` は主要な現行ブラウザで利用できますが、古いブラウザや一部の組み込み WebView では未対応の可能性があります。その場合はブロックモザイクを選択することで代替できます。また、ぼかしは選択範囲の境界外へ広がらないようにクリップしています。

高解像度画像や多数の領域では、一時 Canvas の生成と `getImageData` が処理負荷になるため、現状の最大 4,000 万画素制限を維持します。
